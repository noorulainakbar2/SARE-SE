# Additional Results

This document summarizes the additional experimental results generated during the evaluation of the SARE-SE framework.

## Model Comparison

Performance comparisons were conducted between:

- Baseline Model
- Single-Agent Model
- Multi-Agent SARE-SE Model

The comparison includes Accuracy, Precision, Recall, and F1-score.

## Source-wise Analysis

Performance was evaluated separately for requirements collected from:

- PURE Repository
- GitHub Repositories
- Dronology

## Security Category Analysis

The framework was evaluated across different security categories to assess its ability to classify various types of security requirements.

## Complexity Analysis

Requirement complexity was analysed using three levels:

- Simple
- Moderate
- Complex

## Prediction Results

Prediction files for the baseline, single-agent, and multi-agent models are included in the `results` folder.

Detailed evaluation metrics are also available in the corresponding CSV files.
